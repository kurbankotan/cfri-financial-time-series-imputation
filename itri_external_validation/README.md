# Historical ITRI external validation source

The `classical/` directory preserves the public classical benchmark source,
prespecified 34-ETF universe and protocol. The `neural/` directory preserves
the later BRITS/SAITS source and its own neural protocol. The neural package's
historical README referred to three files supplied by the classical package;
the exact bytes of those files are copied into `neural/` here so its local
documentation is self-contained. These are source archives, not fresh runs or
new confirmatory evidence.
